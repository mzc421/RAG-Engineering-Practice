## 你将学到什么

1. **RAG 流水线**：加载 → 分块 → 嵌入 → 索引 → 检索 → 生成 → 评估  
2. **工程选型**：FAISS / Chroma / Milvus、混合检索、重排、查询改写与路由  
3. **质量意识**：忠实度 / 相关性、LLM-as-Judge、用同一评测集对比策略  
4. **何时上图谱**：关系与多跳场景的边界，以及双引擎降级纪律
